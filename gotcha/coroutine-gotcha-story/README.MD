# What to expect from this project?


1. The goal is to showcase common cases that people get wrong with coroutines
2. Showcase where you need to think a bit
3. How you can generally FIX things



# What not to expect of this project?

1. Explain in depth how things work
2. SUPER accurate clean code





# What top level topics are going to be discussed?



- Lesson 1: Blocking code and suspending
  - What does blocking look like
  - What you should do
  - What should you keep aware off


- Lesson 2: Working with context in thread
  - What happen when you start new coroutine context
  - How and where you could use it
  - What you should be aware off


- Lesson 3: What happens when you block the wrong context


- Lesson 4: SupervisorScope
  - What is it
  - When would you use it
  - What is the gatcha with exceptions
